手机版证件照工具箱（网页版）
============================================================

【这是什么】
和电脑版同一个工具做成的网页版。客户用手机浏览器打开网址就能用：
拍照 → AI 抠图 → 换底色 → 保存，全程在手机上完成，不用装任何 App。

【最重要的一点：必须用 https 网址打开】
手机浏览器规定：只有 https:// 开头的安全网址才允许打开摄像头。
- 用 file:// 或局域网 IP 打开：页面能用，但摄像头会被浏览器禁用
- 所以发布时一定要用带 HTTPS 的托管服务（下面两种任选）

【发布方法一：GitHub Pages（免费，推荐）】
1. 注册 GitHub 账号，新建一个仓库（Repository）
2. 把本文件夹里全部内容上传到仓库：
   index.html、lib、models、clothing 这 4 项都要传
3. 仓库 Settings → Pages → Source 选 main 分支 → Save
4. 等 1-2 分钟，得到网址：
   https://你的用户名.github.io/仓库名/
   （主页是 index.html，直接访问根网址就能打开，不用带文件名）
5. 把完整网址发给客户，微信里点开就能用

【发布方法二：国内对象存储 / 云托管（访问更快）】
- 腾讯云 COS / 阿里云 OSS / 七牛云 等，开通"静态网站托管"
- 把 4 项内容传上去，开启 HTTPS 访问
- 得到 https://xxx.域名/... 网址后发给客户
（这类服务有免费额度，量大再付费）

【本地先体验（可选）】
双击"启动本地测试.cmd"，会自动开本地服务并在浏览器打开完整功能页面，
适合先看看效果。
注意：这只是电脑本机测试；手机通过局域网打开时，
浏览器同样会禁止摄像头，必须上 HTTPS 才能用摄像头。

【手机使用流程】
1. 客户用微信/手机浏览器打开网址。
   第一次加载 AI 模型约 68MB，网速正常要 30-60 秒，
   加载完显示"AI模型就绪"后，以后再用秒开
2. 点"摄像头拍照"，弹出权限询问时点"允许"，
   对准人像直接拍照（没带照片也能现场拍）
3. 自动 AI 抠图 → 选底色 → 背景复杂有毛边时，
   把"收缩强度"调到 2-3，点"收缩边缘"，再点"柔化边缘"
4. 点"保存证件照"下载；iOS 微信里长按图片可"保存到相册"

【常见问题】
- 打开后一直加载：网速慢，多等一会，或换个网络
- 摄像头黑屏/打不开：确认用的是 https 网址，且弹窗点了"允许"
- 保存不了：iOS 微信长按图片保存；Safari 下载的图片在"文件"App 里
- 背景复杂抠不干净：调高"收缩强度"再点"收缩边缘"+"柔化边缘"
- 多人照片会全抠出来，证件照请用单人照

【文件结构（4 项缺一不可，要一起上传）】
index.html            ← 主页
lib/                  ← AI 引擎
models/               ← AI 抠图模型
clothing/             ← 换装素材
